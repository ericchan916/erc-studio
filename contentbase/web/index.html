接入与边界

HOW IT WORKS

Agent 负责产出，底座负责流程。

  1. 本人准备 lark-cli 的 user 授权和明确 Profile。
  2. 绑定自己的飞书 Base / 内容表与字段映射。
  3. 本人配置 yxer；账号和 CLI 凭据留在供应商配置。
  4. Agent 通过 CLI / HTTP 读取素材、提交写计划。
  5. 本人审核，再按冻结版本写回或发布。

完整步骤见源码 README、docs/QUICKSTART.md 和 skills/content-company-base/SKILL.md。

BOUNDARIES

本机单用户，不冒充多租户沙箱。

  • 只监听回环地址，不提供公网服务。
  • 无内置模型调用，不依赖指定 Agent。
  • 浏览器提交素材字节，不提交任意宿主文件路径。
  • 未知执行停止重跑；代码回滚不撤销已发生的外部业务。
  • 默认不连接旧服务、不读取旧账号或历史。
